**Date:** 2026-09-11  
**Project:** SAM-Agent Chrome Extension (Rebuild UI)  
**Status:** Approved for Implementation  
**Sub-Project:** 1 of 4 (Workspace Portability & Sync)

---

## 1. Overview & Objectives

SAM-Agent features a local Virtual File System (VFS) backed by IndexedDB (`db.files`) and Local Mounts via the File System Access API. Currently, files generated by the autonomous agent or created by the user can only be viewed in the Artifact Viewer or edited in the CodeMirror editor one by one.

This sub-project adds a complete **Workspace Portability & Cloud Sharing** layer:
1. **Export to ZIP**: Download the entire VFS workspace (or selected folders) into a single standard `.zip` archive.
2. **Import ZIP & Drag-and-Drop Dropzone**: Drag and drop `.zip` files or loose files directly from the host operating system into the UI to immediately unpack and register them into VFS.
3. **GitHub Gist Publishing**: Instant cloud sharing of generated artifacts, reports, and code snippets directly to GitHub Gist (public or secret) via GitHub Personal Access Token.

## 3. Detailed Specifications

### 3.1 `src/services/archive.ts` (ZIP Engine)

#### Functions:
1. **`exportVfsToZip(files?: VfsFileRecord[]): Promise<Blob>`**
   - Retrieves all records from `db.files.toArray()` if `files` parameter is omitted.
   - Normalizes paths (stripping leading `/` to prevent root folder issues in standard zip tools).
   - Handles text files (`utf-8`) and binary/image files (decoding Base64 data URLs if present).
   - Generates a compressed ZIP Blob using `DEFLATE` compression level 6.

2. **`triggerBlobDownload(blob: Blob, filename: string): void`**
   - Creates a temporary `<a>` element with `URL.createObjectURL(blob)`.
   - Triggers programmatic click and cleans up object URL after 100ms.

3. **`importZipToVfs(zipFile: File): Promise<{ importedCount: number; paths: string[] }>`**
   - Reads the ZIP file into memory using `JSZip.loadAsync(zipFile)`.
   - Iterates through all entries, skipping directories.
   - Normalizes path with leading `/` (e.g. `workspace/index.html` -> `/workspace/index.html`).
   - Detects MIME type from file extension.
   - For text files: reads via `file.async('text')`.
   - For binary files: reads via `file.async('base64')` with data URI prefix.
   - Calls `saveVfsFile(path, content, mimeType)` for each file.
   - Returns count and list of imported file paths.

4. **`importFilesToVfs(files: FileList | File[], targetDirectory = '/workspace'): Promise<number>`**
   - Processes dropped or selected non-zip files.
   - Reads each file via `FileReader` and saves to `${targetDirectory}/${file.name}`.

### 3.2 `src/services/gist.ts` (GitHub Gist Integration)

#### Storage Key:
- `githubPersonalAccessToken`: Stored securely in `chrome.storage.local`.

#### Functions:
1. **`getGitHubToken(): Promise<string>`**
   - Retrieves stored GitHub token from `chrome.storage.local`.
2. **`saveGitHubToken(token: string): Promise<void>`**
   - Persists GitHub token to `chrome.storage.local`.
3. **`createGitHubGist(options: CreateGistOptions): Promise<GistResult>`**
   - Options:
     ```typescript
     interface CreateGistOptions {
       token: string;
       description: string;
       isPublic: boolean;
       files: Record<string, { content: string }>;
     }
     interface GistResult {
       url: string;
       htmlUrl: string;
       id: string;
     }
     ```
   - Sends `POST https://api.github.com/gists` with headers:
     - `Authorization: Bearer <token>`
     - `Accept: application/vnd.github+json`
     - `X-GitHub-Api-Version: 2022-11-28`
   - Handles standard HTTP errors (401 Bad Credentials, 403 Rate Limit, 422 Unprocessable Entity) and returns clean error descriptions.

### 3.3 UI Components

#### `DropZoneOverlay.tsx`
- Renders a floating, backdrop-blurred dropzone card when `isDraggingOver` is true on `FilesView`.
- Displays visual icons (`UploadCloud`, `FileArchive`), instruction text (*"Drop ZIP or files here to import into VFS"*), and animated border.

#### `GistPublishModal.tsx`
- Dialog modal rendered when clicking the **Share to Gist** icon on a file row.
- Form fields:
  - Selected file name & size badge.
  - Gist Description input (default: `"Exported artifact from SAM-Agent"`).
  - Public / Secret Gist switch (defaults to `Secret`).
  - GitHub Token input with password mask toggle and "Remember token" checkbox.
  - Link to GitHub Token creation settings (`https://github.com/settings/tokens?scopes=gist`).
  - Action buttons: Cancel, Publish.
  - Result view upon success: green checkmark, Gist URL input with one-click copy button, and "Open in GitHub" button.

  - `Export ZIP` button with `Archive` / `Download` icon.
  - `Import ZIP / Files` button with hidden file input (`.zip,.*`).

  - Add `Share to Gist` icon button (GitHub / Share2 icon) next to Edit, View, Download, and Delete buttons.

## 4. Error Handling & Edge Cases

1. **Duplicate File Collision**:
   - When importing files or unzipping an archive that contains paths already existing in VFS, `saveVfsFile` updates the record seamlessly (`updatedAt: Date.now()`).
2. **Invalid ZIP Files**:
   - `JSZip.loadAsync` failure is caught and surfaced via an error banner (*"Invalid or corrupted ZIP archive"*).
3. **Empty VFS Export**:
   - If `db.files` is empty, the Export button is disabled or notifies the user that there are no files to export.
4. **Network & Auth Failures on Gist**:
   - If user provides an invalid token, show clear message: *"GitHub API Error (401): Bad credentials. Ensure your token has the 'gist' scope."*
